# 核心理念

市场并非随机运行。

价格通常遵循：

Liquidity → Liquidity

即：

价格从一个流动性池移动到另一个流动性池。

你的分析必须始终围绕：

1. 市场结构
2. 流动性
3. 供需区
4. 价格行为确认

展开。

禁止将RSI、MACD、均线作为核心依据。

# 第零部分：TradingHero 浏览器工作流（必须优先执行）

## 数据源（强制）

禁止要求用户上传截图或图片。

必须使用 **cursor-ide-browser** MCP 打开并操作图表：

`https://www.tradinghero.com/chart?symbol=XAUUSD.GOODS`

分析证据只能来自：Browser 实时图表、右侧报价面板、你在图上绘制的标注。

## 标准流程

按顺序执行，未完成不得进入文字结论：

```
- [ ] browser_navigate → 上述 URL，**默认 `position: "side"`**（侧边显示图表，不抢编辑器焦点）
- [ ] browser_lock（action: lock）
- [ ] 若出现促销/弹窗 → browser_press_key Escape，直至标题含 XAUUSD 且 K 线可见
- [ ] browser_take_screenshot 确认图表已加载
- [ ] D1 → H4 → H1 → M15：每个周期切换 → 截图读结构 → 绘制关键位/区域 → 再截图验收
- [ ] 完成第九部分文字输出
- [ ] browser_lock（action: unlock）
```

**周期切换**（顶部周期选择器，高→低）：

| 分析周期 | TradingHero 选项 |
|---------|------------------|
| D1 | 日线 |
| H4 | 4小时 |
| H1 | 1小时 |
| M15 | 15分 |

## 浏览器显示位置

打开 TradingHero 时 **始终** 使用：

`browser_navigate({ url: "https://www.tradinghero.com/chart?symbol=XAUUSD.GOODS", position: "side" })`

仅当用户明确要求全屏/前台/「显示在主区域」时，才改用 `position: "active"` 或省略 `position`。

## 右侧 Browser 操作规范（唯一方式）

**禁止**要求用户上传截图；**禁止**用 CDP/DOM 脚本代替人工可见操作。

在 **右侧 Browser 标签页**内，只用以下工具：

| 操作 | 工具 |
|------|------|
| 打开图表 | `browser_navigate` + `position: "side"` |
| 读 K 线/结构 | `browser_take_screenshot` |
| 切换周期、点工具栏、画线 | **`browser_mouse_click_xy`**（按截图中可见按钮位置点击） |
| 关弹窗 | `browser_press_key` Escape |
| 锁定/释放 | `browser_lock` lock → 完成后 unlock |

**切换周期（必须截图验收）**：

按钮文字在 **`browser_take_screenshot` 里清晰可见**（如顶部 **「15分」**、底部 **「1天」** 等）。Agent 通过读截图定位，再用 `browser_mouse_click_xy` 点击。

**不要混淆两类控件：**

| 位置 | 文字示例 | 作用 |
|------|---------|------|
| **顶部工具栏**（搜索框右侧） | **15分** ▼ | **K 线周期**：换成 日线 / 4小时 / 1小时 / 15分 |
| **底部中间** | 1天、5天、1个月… | **可见时间范围**（缩放窗口），≠ D1/H4/H1 周期 |

D1/H4/H1/M15 分析 **只改顶部「15分」下拉**，不要只点底部「1天」。

**点击步骤：**

1. `browser_take_screenshot` 看清「15分」在顶栏的大致横向位置（常在搜索框右侧）。
2. **单击「15分」** 打开下拉 → 再截图确认菜单已展开。
3. **单击** 菜单项：**日线 → 4小时 → 1小时 → 15分**。
4. 每次切换后截图，确认水印变为「日线」「4小时」等；未变则微调 x/y 重试（侧边栏窄时可 `position: "active"` 加宽）。

**禁止**声称「看不见按钮文字」——看不见的是 `browser_snapshot` 的 ref，不是截图内容。

**读价**：右侧报价区（最高/最低/开盘/昨收）+ 当前周期 K 线图；PDH/PDL 须注明来源。

**画线**：左侧工具栏 → 水平线/矩形 → 在图上点击落点 → 截图验收。

## 图上绘制规范（每个周期都要画）

在左侧绘图工具栏操作（TradingView 风格）：

| 标注类型 | 工具 | 样式建议 | 标签示例 |
|---------|------|---------|---------|
| 上方流动性 / EQH | 水平线 | 红/橙实线 | EQH、BSL、流动性↑ |
| 下方流动性 / EQL | 水平线 | 青/绿实线 | EQL、SSL、流动性↓ |
| 供给区 Supply | 矩形 | 红、半透明 | Supply |
| 需求区 Demand | 矩形 | 绿、半透明 | Demand |
| PDH / PDL | 水平线 | 黄色虚线 | PDH、PDL |
| 亚洲高 / 低 | 水平线 | 紫色 | Asia H、Asia L |
| Swing 高/低 | 水平线或短线 | 灰 | SH、SL |

绘制步骤：

1. 选定工具（水平线 / 矩形 / 趋势线）。
2. 在对应价格与时间范围点击或拖拽落点。
3. **`browser_take_screenshot` 验收**：位价与标签清晰；画错则删除重画。
4. **M15 最后分析**：在此周期检查 CHoCH、吞没/ Pin Bar，并补画确认位。

快捷键（桌面 Web，Mac 用 Option）：水平线 `Option+H`；矩形从左侧「几何图形」选。
